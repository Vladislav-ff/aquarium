# Аудит NACRE Pages 4.3

## Исходная база

Проверен доступный NACRE IV из aquarium.html; точный исходник и SHA256 включены. NACRE VI недоступна, поэтому её функции не приписываются этой сборке. Полный запуск настоящей Three.js в этой среде не подтверждён.

## Сохранённые исправления

Физика отделена от настройки качества и выполняется одним тестируемым FixedStepper 60 Гц. Анатомия и shader-time согласованы с фактическими шагами. Добавлена пауза без накопления скрытого wall time. RAF отменяется в фоне и восстанавливается после BFCache одной цепочкой. Ошибки кадра и потеря WebGL останавливают сцену с видимой ошибкой.

Видимость проверяет конечные цилиндры с крышками, а не эллипсоиды вместо них. Обработаны отрезки с началом внутри. Контактные буферы растут. При прыжке освобождается кормовая заявка, устаревшие слоты защищены. LOD не оживляет неактивных рыб. Численные входы волновой сетки проверяются.

Resize объединяется таймером, DPR обновляется, сторона буфера преломления ограничена 1024. Между проходами используется рассчитанная теневая карта; динамические атрибуты помечены DynamicDrawUsage. Выключенный звук приостанавливается после fade; таймеры и аудиоконтекст корректно очищаются. Не заявляется измеренный рост FPS.

## Новое завершение проверки в 4.3

- Проверка vendor теперь подтверждает не только SHA256 отдельных файлов, но и полноту транзитивных импортов.
- Вынесены и тестируются извлечение импортов, aliases three/addons/ и ограничения закреплённого пакета. Обычные примеры импортов в starred JSDoc не трактуются как зависимости.
- Синтетические интеграционные тесты проверяют полную локальную сборку, отсутствие транзитивного файла и изменение байтов зависимости.
- Staging включает только публикуемые файлы, без исходников, тестов и оригинала.
- Добавлены детерминированная упаковка замороженного дерева и независимая проверка ZIP CRC/путей/полноты SHA256-манифеста.
- В реальном браузерном тесте блокируется любой нелокальный запрос, не только HTTPS.
- SOURCE.json фиксирует точную область сборки без случайных временных меток.

## Публикация и зависимости

Есть index.html, .nojekyll, относительные пути, webmanifest, 404, иконка. Сборка именует CSS/JS по содержимому и сохраняет цепочку boot → scene → physics. Исторические версии не удаляются автоматически при последующих сборках. Отдельный сервер/Node на Pages не нужен.

Стандартный ZIP использует CDN. Workflow и ручной vendor дают same-origin библиотеки только после успешного выполнения подготовки. Three.js закреплена на 0.169.0; лицензия и checksums добавляются при vendor. Предыдущий каталог сохраняется, если подготовка нового графа завершилась ошибкой. Настоящие библиотеки в этой среде не скачивались.

## Фактические результаты

42/42 Node-теста: численные волны, отрезки, узкая фаза на минимальной математической фикстуре, буферы, планировщик, import utilities и искусственный vendor-граф. 9/9 Chromium shell-проверок: корень и project prefix, отказ библиотеки, повторный экономичный запуск, отсутствие потерянных локальных ресурсов и необработанных ошибок, мобильная ширина при подставной сцене.

Успешный shell-bootstrap с подставным модулем НЕ является проверкой GPU. Режим --real3d с настоящими библиотеками предусмотрен перед deploy в workflow, но здесь не выполнялся. GitHub workflow в реальном репозитории не запускался. Нет утверждения «все возможные ошибки исправлены».
