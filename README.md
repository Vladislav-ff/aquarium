# NACRE VI — автономная экосистема

## Быстрый запуск

Откройте `aquarium.html` в современном браузере. Это готовый единый HTML: остальные файлы рядом ему не нужны.

- При доступном CDN загружается сохранённая 3D-сцена на Three.js 0.169.0.
- Если CDN недоступен, автоматически включается 2D-режим с тем же движком.
- Для гарантированного офлайн-запуска добавьте к адресу `?renderer=2d` либо выберите «2D · без Интернета» в панели экосистемы.
- Если браузер ограничивает запуск из файла, запустите `python -m http.server 8000` в папке проекта и откройте `http://localhost:8000/aquarium.html`.

## Управление

Кнопка «Экосистема ↗» — численность, график, скорость, пауза, сохранения и журнал.
Нажатие на рыбу — возраст, размер, энергия, здоровье, выносливость и поколение.

- Пробел — пауза / продолжение.
- F — режим ручного кормления; затем нажмите в воде.
- N — ручное переключение света, выключает автоматический цикл.
- J — попросить подходящую рыбу прыгнуть; требуется запас энергии и окончание отдыха.
- H — исходная камера в 3D.
- Esc — закрыть панели и отменить кормление.

В 3D доступны вращение камеры, следование, макрообзор, течение, вода и процедурный звук. В 2D неподдерживаемые 3D-контролы не используются. Звук запускается только по нажатию.

## Модель

Планктон восстанавливается из минерального пула при свете. Рыбы расходуют пищу на обмен, рост и кладку. Органика минерализуется. Ручной корм необязателен и учитывается как внешний приток вещества.

Все скорости времени согласованы: ×2/×4 ускоряют весь мир, а не только метаболизм. Шаг — 1/30 модельной секунды. За кадр выполняется не более 12 шагов. При перегрузке время замедляется; состояния не перепрыгиваются.

Лимит — 96 рыб и икринок вместе, на новом мобильном биотопе — 64. Вид может вымереть; автоматического подселения нет. Крабы и медуза — декоративные, вне пищевой сети.

Это вымышленная модель с условной биомассой и кислородом, не научный или ветеринарный симулятор. Рыбы сталкиваются приближёнными капсулами; точность тонких плавников не моделируется. Визуальные камни и их коллизионные эллипсоиды также приближённые.

## Сохранения

Автосохранение каждые 15 секунд и при скрытии/закрытии страницы. Состояние хранится в localStorage этого браузера и адреса. Есть резервная копия предыдущего корректного сохранения. Если браузер блокирует хранилище, интерфейс предупреждает об этом.

JSON-экспорт и импорт переносят позиции, скорости, параметры рыб, икру, корм, ресурсы, время и генератор случайных чисел. Неверные или несбалансированные файлы отвергаются до замены текущего мира. Максимальный размер импорта — 1 МБ. Старый экспериментальный формат v5 не импортируется как v6.

При скрытой вкладке и после закрытия страницы время не идёт. Офлайн-догоняния нет. Между несколькими открытыми вкладками одного адреса нет распределённой синхронизации; используйте один активный экземпляр для одного сохранения.

## Исходники и сборка

- `ecology-core.js` — единая модель биологии, движения и коллизий без браузерных зависимостей.
- `ecology-app.js` — единственный планировщик, интерфейс, 2D-рендерер и сохранения.
- `aquarium-scene.mjs` — адаптер исходной процедурной 3D-сцены.
- `aquarium.template.html` — шаблон сборки.
- `build.py` — сборка единого HTML; запуск `python build.py`.
- `tests.cjs` — тесты точного поставляемого движка; запуск `node tests.cjs`.
- `node tests.cjs --endurance` — дополнительно час модельного времени с реальным движением и коллизиями. Требуется Node.js 18+; npm-пакеты не нужны. Этот тест может занимать несколько минут.

`AUDIT.md` объясняет исправления и границы проверок. JSON-отчёты содержат результаты выполненных тестов. `NACRE.audit()` и `NACRE.validate()` в консоли браузера показывают и проверяют состояние.

## Зависимости и приватность

Единственная внешняя зависимость для 3D — Three.js из CDN jsDelivr. В 2D внешних библиотек нет. Код не отправляет сохранения или действия пользователя на сервер. Для 3D браузер делает обычные сетевые запросы за библиотекой; CDN видит технические данные этих запросов.
